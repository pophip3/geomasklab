# Changelog

This repository is a private research development branch. Entries describe
implemented changes, not an approved public release or journal acceptance.

## 0.9.0-dev.3 — 5 October 2026

- Defined the version 1.0 functional scope, users, application context and
  source-first distribution plan using published SoftwareX repositories as references.
- Added explicit offline region recalculation for saved and imported masks,
  with separate result versions, pending review and retained prediction provenance.
- Added independently verified selected-region denominators and within-region
  coverage while preserving the existing whole-image coverage definition.
- Kept older evidence bundles readable and added tests for re-signed coverage
  faults, complement retention, source preservation, reload and HTTP export.
- Added a model-free investigation example checked against direct Pillow crops.
- Complete English-language conversion and formal licensing remain pending.

## 0.9.0-dev.2 — 5 October 2026

- Added verified cross-session evidence import and review persistence.
- Added an optional Label Studio SDK brush-prediction bridge and controlled
  artifact/metadata handoff checks; full Label Studio GUI acceptance remains pending.
- Verified the source version on Windows, Linux and macOS with Python 3.10/3.13.
