# Reproduce paper results

Manuscript: **GeoMaskLab: Replayable measurements for segmentation masks**.

Install from `main` using the pinned commands in the [README](../README.md#installation).
The paper implementation is fixed at
[`2be0c18f54333df2f560b8ae8a9311ae0a6b267f`](https://github.com/pophip3/geomasklab/tree/2be0c18f54333df2f560b8ae8a9311ae0a6b267f).
The helper added on `main` uses the same measurement core and bundled NAIP data.

## Bundled pixel measurements

From the repository root, after installation:

```powershell
.\.venv\Scripts\python.exe examples/reproduce_paper_results.py
.\.venv\Scripts\geomasklab.exe verify output/paper-results/whole.zip
.\.venv\Scripts\geomasklab.exe verify output/paper-results/right.zip
.\.venv\Scripts\geomasklab.exe verify output/paper-results/valid.zip
.\.venv\Scripts\geomasklab.exe verify output/paper-results/empty.zip
.\.venv\Scripts\geomasklab.exe verify-comparison output/paper-results/whole-right-comparison.zip
```

On Linux/macOS, use `.venv/bin/python` and `.venv/bin/geomasklab`.
Expected coverage is 54.41%, 48.09%, 53.52% and undefined, respectively.
The common-domain changed-pixel count is zero, and the saved total and
excluded-domain changes are both -79,601 pixels.
The helper checks the input hashes, integer counts and ratios and exits nonzero
on a mismatch. Use `--output output/paper-results-2` for another run.

## Numerical records for Table 4 and the water assessment

Download `GeoMaskLab_Supplementary_Experiment_Records.zip` from
[Zenodo record 23397371](https://doi.org/10.5281/zenodo.23397371).
Its published MD5 is `241a4746e7431954d8ff89443b75be2f`.
Keep the ZIP in the repository root and run:

```powershell
.\.venv\Scripts\python.exe examples/reproduce_paper_results.py --records GeoMaskLab_Supplementary_Experiment_Records.zip --output output/paper-results-with-records
```

`table4_metrics.csv` reproduces each row to the paper's two decimal places.
Whole and Right also supply the twelve values plotted in Supplementary Figure S1.
`water_metrics.json` sums the 65 scene records and checks TP 1,356,978,
FP 35,782 and FN 256,701, with IoU 82.27%, Dice 90.27%, precision 97.43%
and recall 84.09%. Of 28 scenes with no labelled water, five have false positives.
These commands recalculate the published numerical records.

## Model reconstruction

The same Zenodo record provides `GeoMaskLab_Supplementary_Reproducibility_Evidence.zip`.
Extract it into a separate directory:

- Six-image WHU/iSAID experiment: follow `public-model-case/README.md` for official
  inputs, fixed sample selection, RemoteSAM assets, inference and measurement.
  This case uses 896 x 896 model inputs, threshold 0.5 and restoration to the source grid.
- Figure 5 aircraft case: follow
  `current-software-runs/current-software-results-20261007/reviewer-reproduction/README.md`.
- Water evaluation: `water_model_provenance.json` in the records identifies the
  v5 checkpoint (`ef86d7d5c4e1b9c30762f72a5435b59efe2da917e5a04a9b2364bf977a85596e`).
  Source label rasters and that checkpoint are not included in the deposit;
  the supplied per-scene counts support numerical recalculation.

The reconstruction guides identify the separately obtained imagery, labels and
weights. The six-image and P1133 prediction rasters are regenerated by inference.

## Replay the seven archived publication packets

With the GeoMaskLab environment installed, change to the extracted supplement:

```sh
python release-v1.0.0/replay_publication.py --archive release-v1.0.0/GeoMaskLab-rc4-publication-packets.zip --output reader-replay
```

Use the absolute path to the installed environment's Python if it is not activated.
Expected result: `packet_count: 7`, `all_passed: true`.
These are the historical controlled packets listed in the supplement.
